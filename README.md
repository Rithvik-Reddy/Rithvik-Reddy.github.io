# Professional Portfolio

MS in Applied AI, Indiana Wesleyan University.

## Setup

1. Create a public GitHub repo named `yourusername.github.io`.
2. Upload every file in this folder to the repo root.
3. Open Settings, then Pages. Set Source to "Deploy from a branch." Select `main` and `/ (root)`. Save.
4. Wait a few minutes. The site publishes at `https://yourusername.github.io`.
5. Open the URL in a private browser window. Confirm it loads with no sign-in prompt.

## Files

- `_config.yml` — Jekyll theme and site title
- `index.md` — home page, bio, value proposition
- `artifacts.md` — artifact index
- `artifact-1.md` — Workshop 1 artifact
- `artifact-2.md` — Workshop 2 artifact
- `assets/` — screenshots, downloads, evidence files

## Before submitting

- Replace every `[REPLACE: ...]` block.
- Confirm all nine artifact headings are present and filled.
- Confirm every image loads and every download link resolves.
- Proofread. The rubric penalizes typos.
- Submit the live URL, not the repo URL.
- Write the reflection in the Brightspace text area. Do not put it in the portfolio.
